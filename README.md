# Graph Tool

CLI-инструмент для анализа и визуализации графа зависимостей менеджера пакетов.

Визуализация графа. Инструмент строит граф транзитивных
зависимостей по индексу пакетов, выводит его в виде ASCII-дерева, формирует
текстовое представление на языке Mermaid и сохраняет изображение в формате
PNG. Поддерживаются ограничение глубины, фильтрация пакетов, обработка
циклических зависимостей, режим порядка загрузки и тестовый режим.

## Возможности

- Ограничение глубины анализа (`--max-depth`).
- Фильтрация пакетов по подстроке (`--filter`).
- Обработка циклических зависимостей без зацикливания.
- Вывод порядка загрузки зависимостей (`--load-order`).
- Вывод ASCII-дерева зависимостей (`--ascii-tree`).
- Формирование Mermaid-представления графа (`--mermaid`).
- Сохранение графа в PNG без внешних зависимостей (`--output *.png`).
- Сохранение Mermaid в файл (`--output *.mmd` или `*.mermaid`).
- Сохранение исходника в формате DOT (`--output *.dot`).
- Поддержка локальных файлов и удалённых репозиториев (`--mode`).

## Требования

- JDK 17 или новее.
- Доступ в интернет — только если используется удалённый URL репозитория.
