# Graph Tool

CLI-инструмент визуализации графа зависимостей для менеджера пакетов.

**Этап 2** — сбор данных о прямых зависимостях пакетов Ubuntu (apt).
Информация извлекается напрямую из индекса `Packages.gz`.

## Требования

- JDK 17 или новее
- Доступ в интернет (если используется удаленный URL-адрес репозитория)

## Сборка и запуск

Проект поддерживает сборку через `Makefile`:

```bash
make build                          # компиляция проекта
make run ARGS="--help"              # вывод справки
make test                           # запуск тестов
make clean                          # очистка папки сборки (out/)
