# Graph Tool

CLI-инструмент для визуализации графа зависимостей менеджера пакетов.

**Этап 3** — построение графа транзитивных зависимостей с помощью итеративного DFS.
Поддерживается ограничение глубины, фильтрация пакетов, корректная обработка циклических зависимостей и тестовый режим.

## Требования

- JDK 17 или новее
- Доступ в интернет (если используется удаленный URL-адрес репозитория)

## Сборка и запуск

```bash
make build                          # компиляция проекта
make run ARGS="--help"              # вывод справки
make test                           # запуск тестов
make clean                          # очистка папки сборки (out/)
